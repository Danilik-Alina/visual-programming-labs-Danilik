\## Освоенные ноды

\* \*\*Manual Trigger\*\* — ручной запуск.

\* \*\*Set (Edit Fields)\*\* — задание статических полей (payload, topic, timestamp).

\* \*\*Code (JavaScript)\*\* — написание логики (let/const, if/else, циклы, работа с объектами).

\* \*\*IF\*\* — ветвление по условиям.

\* \*\*HTTP Request\*\* — выполнение GET-запросов к публичному API.

\* \*\*Schedule Trigger\*\* — запуск по расписанию.

\* \*\*Redis\*\* — операции Set, Get, Delete для работы с базой данных.

\* \*\*NoOp\*\* — пустая операция (заглушка).
