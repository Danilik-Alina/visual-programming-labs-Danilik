# Лабораторная работа №3. Bubble

## 1. Краткое описание выполненного
В ходе выполнения работы было создано приложение-энциклопедия «Вселенная Стивена Кинга» на платформе Bubble с помощью AI-генерации.

## 2. Промпт дословно (из Части 1)
> Создай приложение на тему «Вселенная Стивена Кинга: интерактивная энциклопедия».
> Пусть этот сайт будет публичный, без обязательной регистрации.
> Страницу обязательно создай по структуре header + body + footer.
> Обязательно укажи в заготовке следующую строку: «ТВП: Даналик Алина»
> Добавь несколько интерактивных элементов (реализующих CRUD), например, для добавления и просмотра записей о книгах, персонажах или местах из произведений.

## 5. Какие элементы и workflows освоены
В ходе работы были освоены следующие элементы и функции Bubble:
*   **UI Elements:** Text, Button, Input, Repeating Group, Group.
*   **Components:** Готовый компонент Footer.
*   **Data:** Создание Data Type (Персонаж), добавление полей, ручное заполнение App Data.
*   **Workflows:** Создание (Create a new thing), Удаление (Delete a thing).
*   **Global Variables:** Создание и применение цветовой переменной.
