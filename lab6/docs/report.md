## Часть 1. Базовое задание «Приветствие»

### Описание приложения
Создано приложение, которое здоровается с пользователем по введенному имени. На главном экране (Screen1) расположена фамилия студента на английском языке (Danilik) — обязательное требование.

**Реализованные компоненты:**
*   Label (Фамилия студента)
*   Label (заголовок «Введите имя»)
*   TextBox (поле ввода с Hint = «Ваше имя»)
*   Button (кнопка «Поздороваться»)
*   Label (вывод результата)

**Логика (блоки):**
При нажатии на кнопку `Button1` проверяется условие (`if`):
1.  Если `Text_Box1.Text` пустой (равен `""`), в результирующий `Label3` выводится текст «Введите имя!».
2.  Иначе (`else`) с помощью блока `join` формируется строка приветствия: «Привет, » + `Text_Box1.Text` + «!», которая выводится в `Label3`.
